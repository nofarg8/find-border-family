# אבודים - גרסת הבורדר קולי

דף נחיתה לסקר ההיתכנות: מסביר בקצרה על הרעיון ושולח לטופס ההרשמה לרשימת המתעניינים.

- `index.html` - הדף (מותאם למובייל)
- `og-image.jpg` - התמונה שמופיעה כשמשתפים את הלינק בוואטסאפ
- `img/` - האיורים
- `fonts/`, `fonts.css` - הגופנים (מתארחים כאן, בלי תלות בגוגל)
